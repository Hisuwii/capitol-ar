# Image Target

Place your compiled MindAR target file here:

    cu-logo.mind

HOW TO GENERATE IT
==================
1. Go to: https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. Upload the official CU logo image (JPG or PNG).
3. Click "Start" and wait for compilation.
4. Download the generated .mind file.
5. Rename it to: cu-logo.mind
6. Place it in this folder.

Tips for best tracking:
- Use a high-contrast, detail-rich version of the logo.
- Avoid plain/flat logos with little texture — they track poorly.
- The larger the printed logo, the better the recognition distance.
