# 3D Mascot Models

The mascots are now built procedurally in js/mascot-viewer.js (Three.js
primitives, stylised low-poly, animated), so no GLB files are required.

| Dept  | Mascot          | mascot_type (data/departments.json) |
|-------|-----------------|-------------------------------------|
| CCS   | Falcon          | falcon    |
| CHS   | Python          | python    |
| CED   | Blue Phoenix    | phoenix   |
| CCrim | Purple Warrior  | warrior   |
| COE   | Beaver          | beaver    |
| CBA   | Eagle           | eagle     |
| CAS   | Red Knight      | redknight |
| CME   | Dolphin         | dolphin   |

To change a mascot, edit its `mascot_type` / `mascot_name` in data/departments.json.
